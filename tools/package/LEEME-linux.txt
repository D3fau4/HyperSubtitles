HyperSubtitles ({version}) - Linux
================================

mod/  -  Subtítulos en el juego (Steam con Proton)
  Copia winmm.dll, subtitles.json y dialoguebox.json en la carpeta del juego
  (junto al ejecutable de Neptunia Re;Birth1). La fuente del juego
  (FOT-NewRodinPro-EB.otf) ya está en esa carpeta; no hace falta copiarla.
  Proton usa su propio winmm.dll: en Steam, Propiedades > Opciones de lanzamiento:
    WINEDLLOVERRIDES="winmm=n,b" %command%

editor/  -  Editor de traducciones (Linux x86_64)
  Ejecuta ./HyperSubtitlesEditor. Encuentra solo la carpeta data/ y los retratos
  de faces/ que hay a su lado.
  - Necesita OpenGL 3 y X11 o Wayland (cualquier escritorio normal los tiene).
  - La primera vez abre Ajustes: elige la carpeta del juego (la de Steam, p. ej.
    ~/.steam/steam/steamapps/common/...) para tener la preview exacta (fuente del
    juego) y poder escuchar las voces (data/SOUND.xsb/xwb).
  - Idioma de la interfaz: Ajustes > Interfaz > Idioma (español / inglés).
  - Archivo > Exportar subtitles.json... genera el archivo para el mod, y
    "Exportar e instalar en el juego" lo copia directamente con dialoguebox.json.
  - Las traducciones se guardan en editor/data/lines/*.json: comparte esa carpeta
    para juntar el trabajo.

----

mod/  -  In-game subtitles (Steam with Proton)
  Copy winmm.dll, subtitles.json and dialoguebox.json into the game folder (next
  to the Neptunia Re;Birth1 executable). The game font is already there.
  Proton ships its own winmm.dll: in Steam, Properties > Launch options:
    WINEDLLOVERRIDES="winmm=n,b" %command%

editor/  -  Translation editor (Linux x86_64)
  Run ./HyperSubtitlesEditor; it finds data/ and faces/ next to it. It needs
  OpenGL 3 and X11 or Wayland. On first run, set the game folder in Settings for
  the exact preview and the voices. Interface language: Settings > Interface >
  Language.
